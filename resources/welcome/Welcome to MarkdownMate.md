# Welcome to MarkdownMate

This folder is yours. Every note in it is a plain Markdown file (`.md`) on your disk, so any app can open it and any sync service can carry it: iCloud Drive, Dropbox, Syncthing or Git. Nothing is locked in.

Click anywhere in this note and start typing. It saves as you go.

## Write with Markdown

A few characters give your text its shape:

- `#`, `##` or `###` and a space at the start of a line make a heading
- Two asterisks make text **bold**, one makes it *italic*
- A dash and a space start a list, like this one

## Keep a to-do list

- [x] Open MarkdownMate
- [ ] Read this note to the end
- [ ] Write your first note

Tick a box with a click in the preview, or type an x between its brackets.

## Link your notes

Put a note's name in double square brackets to link to it, like this: [[Getting Around]]. Open a link with ⌘-click on a Mac, Ctrl+click on Ubuntu, or a click in the preview. A link to a note that doesn't exist yet creates it when you open it.

## Tag them

Write a tag anywhere in a note, like #welcome, and the sidebar's Tags section gathers every note that has it.

## Make a point stand out

> [!tip] Callouts
> Start a quote with `[!tip]`, `[!note]` or `[!warning]` and the preview shows it as a coloured box, like this one.

## Add images

Paste an image (⌘V on a Mac, Ctrl+V on Ubuntu) or drop one into a note. MarkdownMate saves it in an assets folder next to the note and links it for you.

## Today's Note

Press ⌘D on a Mac, Ctrl+D on Ubuntu, to open today's note. It is created the first time, named after the date, so a journal or a work log is one key away.

## Templates

The Templates folder holds four ready-made notes: Meeting Notes, Project, Book Notes and Weekly Review. Choose New from Template (in the File menu on a Mac, the main menu on Ubuntu) to start a note from one. Edit them or add your own: every note in that folder is a template.

When you know your way around, delete this note and make the folder your own.
